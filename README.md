# MMA Kids V2（提案互動 Demo）

本專案為提案概念展示，非永豐銀行正式產品；人物、金額及合作條件皆為示意。

## 預覽
GitHub Pages 發布後，請開啟 `https://<你的帳號>.github.io/SinoPac/demo/`。

## 本次修正
- ETA 以預估的每週儲蓄額及實際可適用的配對比例／上限估算，不再直接把每週配對上限當成必然收入。
- 預算進度條增加零預算防呆，避免除以零。
- 分享罐文字明確說明為預留金額，不會自動捐款，也不強制連結公益機構。

## 檔案
- `demo/`：互動展示頁
- `docs/`：提案規格與 Demo 備註（如需可自行放入）

- 三個錢罐皆可點擊：儲蓄進入夢想基金、消費進入日常錢包、分享顯示分享金用途說明。
