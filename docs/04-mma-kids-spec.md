# 04｜MMA Kids App 規格書（Demo 改版用）

> 這份文件說明如何把現有的「大戶 Junior」Demo 改成「人生第一個帳戶：MMA Kids」版本。
> 寫法以「畫面上有什麼、按下去會發生什麼、示範數字是多少」為主，方便直接對照 `demo/app.js` 修改。
>
> ⚠️ 本專案為學生提案的概念展示，並非永豐銀行正式產品。人物、金額、合作條件皆為示意。

---

## 0. 一頁看懂改版重點

### 產品一句話

> **MMA Kids：永豐 MMA 兒童帳戶的延伸。孩子用 MMA Kids App 管理自己的錢，家長在 DAWHO App 的「親子」分頁陪伴與管理。**
>
> 存起來，媽媽陪你存；完成任務，爸媽送你禮物。

### 與原本大戶 Junior 的差異

| 類型 | 項目 | 說明 |
|---|---|---|
| 改名 | 大戶 Junior → **MMA Kids** | 定位改為「永豐 MMA 兒童帳戶的延伸」，孩子端 App 名稱、標題、Logo 文字全部改成 MMA Kids |
| 改名 | DAWHO › Junior → **DAWHO › 親子** | 家長端仍在 DAWHO App 內，分頁名稱改為「親子」，畫面標題為「小安的 MMA Kids」 |
| 修改 | 存錢目標 → **夢想基金** | 加入「家長配對」：家長自選比例與上限，配對款保留到達標才撥入 |
| 修改 | 付款前提醒 | 從「晚 X 天達成」改成「買下去／存起來」二選一，並顯示「存起來」後夢想進度增加幾 % |
| 修改 | 獎勵規則（達標加碼 200 等） | 刪除。改為：夢想基金＝家長配對（錢）；任務＝非金錢禮物 |
| 修改 | 零用錢 | 改為**選填**。家長可以不設定或暫停，孩子仍可用紅包、存款使用夢想基金 |
| 新增 | **任務** | 家長出題＋選禮物 → 孩子去做 → 家長按「已完成」→ 孩子端顯示「禮物到手」 |
| 新增 | **配對暫停** | 家長可隨時暫停配對；孩子端只顯示「配對暫停中」，不顯示原因 |
| 新增 | **需要家長同意的交易** | 超過單筆門檻、新增收款人、夢想基金提前領出，需家長在 DAWHO 同意 |
| 新增 | **幫我看看** | 孩子貼上可疑訊息或連結，App 提示常見詐騙特徵 |
| 新增 | **信託與 18 歲升級** | 家長端可看信託；18 歲從 MMA Kids 升級為 DAWHO |
| 保留 | 學堂 | 保留課程＋小測驗格式，課程聚焦「聰明消費」「存錢」「防詐」三類，並可連動任務 |
| 保留 | 帳本、需要／想要、每週回顧 | 沿用原設計 |
| 保留 | 防詐：陌生入帳先保留、交易當下提醒、遇到可疑的事 | 沿用原設計，整合進「安全與管理」三層架構 |
| 保留 | 家長查看程度依年齡分層 | 沿用原設計（7–12／13–15／16–17 歲） |
| 拿掉 | AI 理財小幫手 | 孩子端不再有「小幫手」分頁；防詐問答改由「幫我看看」與學堂承接 |
| 拿掉 | 我的資產、投資權限、配息通知 | 不再顯示證券親子帳戶，相關課程（股票與 ETF、風險與分散）一併移除 |
| 拿掉 | 功能解鎖（轉帳給朋友、定存、外幣、自己投資） | 首頁不再有灰色鎖住卡片；「定存與利息」課程移除 |

## 1. 整體架構

```
┌─────────────────────────────────────────────────────────────┐
│ 家長｜DAWHO App › 親子分頁                                      │
│ 撥零用錢（選填）· 自選配對比例 · 出任務、按完成 · 安全設定 · 查看信託   │
└─────────────────────────────────────────────────────────────┘
            ↓ 親子連結（即時同步）
┌───────────────────────────────────────┐ ┌──────────┐ ┌──────────┐
│ 孩子｜MMA Kids App（7–17 歲）            │ │ 長期｜信託  │ │ 18 歲後    │
│ 夢想基金＋家長配對 · 任務達成 · 學堂        │ │ 家長每月存入 │ │ 升級 DAWHO │
│ 帳本 · 安全（遇到可疑的事、幫我看看）       │ │ 15/18 歲給付│ │ 自己管理    │
└───────────────────────────────────────┘ └──────────┘ └──────────┘

時間軸：7 歲 開立 MMA 兒童帳戶 ── 15 歲 信託第一次給付 → MMA ── 18 歲 升級 DAWHO＋信託給付 → DAWHO
```

### 兩個核心機制的分工（很重要，畫面上不可混在一起）

| | 夢想基金 | 任務 |
|---|---|---|
| 換到什麼 | 錢（孩子存的＋家長配對） | 非金錢禮物（例：週末看電影） |
| 誰決定 | 系統依家長設定的比例自動計算 | 家長按「已完成」 |
| 經過帳戶嗎 | 是（配對款先圈存在家長帳戶，達標才撥入） | 否，App 只做記錄 |
| 顏色 | 藍色（我存的）＋粉紅（家長配對） | 暖黃 |

### 色彩規則（兩端一致）

| 顏色 | 代表 | 色碼建議 |
|---|---|---|
| 綠色 | 可以花的錢、學堂 | `#2F8F6B` |
| 藍色 | 夢想基金（我存的） | `#3A6EA5` |
| 粉紅 | 家長配對 | `#C8454F` |
| 暖黃 | 任務與禮物 | `#B7791F` |
| 紫色 | 信託 | `#7B61A8` |
| 灰色 | 18 歲／DAWHO、配對暫停中、求助按鈕 | `#6B7280` |

風格：淺色背景、圓角卡片、大量留白；每個畫面只有一個最大的數字。

## 3. 孩子端：MMA Kids App

底部 5 個分頁：**首頁／夢想／任務／學堂／帳本**（拿掉原本的「小幫手」）。

### 3.1 首頁

由上到下：

1. 問候：「嗨，小安」＋小字「MMA Kids｜週五」
2. **可以用的錢**（全頁最大字，綠色）：`$320`
3. 小字：「本週還能花 $180」
   - 若家長**沒有設定零用錢**：不顯示這一行
4. 夢想小卡（藍底）：「球鞋基金 62%」＋雙色進度條（藍＝我存的、粉紅＝媽媽保留的）→ 點擊進入「夢想」分頁
   - 若配對暫停：粉紅段改為灰色（見 5.4）
5. 任務小卡（暖黃底）：顯示一個進行中的任務，例：「這週不超支｜第 5/7 天｜🍕 選一次晚餐」→ 點擊進入「任務」分頁
6. 兩個安全按鈕並排：
   - 「遇到可疑的事」（灰色）→ 見 3.8
   - 「幫我看看」（灰色）→ 見 3.8
7. 小字：「媽媽可以看到：每筆消費和品項」（依年齡分層變化，見 4.5）

### 3.2 付款（買下去／存起來）

觸發：孩子出示付款碼，店家掃碼後進入確認畫面。

**是否跳出二選一**（沿用原本提醒條件）：
- 消費類別為飲食、娛樂，**且**金額 ≥ $50；或單筆 ≥ 本週還能花的一半
- 同一天最多 2 次；交通、文具類直接付款，不跳出

**畫面元素**：
1. 店家「全家便利商店」、品項「珍珠奶茶 $70」
2. 小標：「這 $70 你想怎麼用？」
3. 選項 A 卡片（灰底）：
   - 左：「買下去」　右：「球鞋 62%」
   - 小字：「夢想進度不變」
4. 選項 B 卡片（藍框）：
   - 左：「存起來」　右：「62% → 69%」
   - 迷你進度條：藍（原本）＋淡藍（+$70）＋淡粉紅（+$50）
   - 小字：「我 +$70　媽媽配對 +$50」
   - 小字：「夢想進度 +7%」
5. 底部小字：「不會擋你付款，選一個就好」

**按下後**：
- 「買下去」→ 完成付款 → 跳出「需要／想要」標記（沿用原設計）
- 「存起來」→ 不付款；$70 從可以用的錢轉入球鞋基金 → toast：「存進球鞋基金 $70，媽媽陪你存 $50」→ 返回首頁，夢想小卡更新為 69%

**進度計算**：見 5.1。

### 3.3 夢想（夢想基金頁）

1. 標題「球鞋基金」＋小字「目標 $1,800」
2. 大字：`62%`（藍色）
3. 雙色進度條
4. 三列明細：我存的 $820（藍）／媽媽保留的 $300（粉紅）／還差 $680（灰）
5. 綠底小卡：「預計 12/27 達成」
6. 小字：「這週日 20:00 結算媽媽的配對」
7. 按鈕「存一筆進來」→ 底部彈出：
   - 輸入金額（從可以用的錢轉入）
   - 來源標籤（選填）：零用錢剩下的／紅包／親友給的／其他
   - 確認後進度更新；是否配對依家長勾選的來源決定
8. 次要連結「提前領出」→ 見 3.8「需要家長同意的交易」

**孩子端不顯示**：配對比例、公式、上限數字。孩子只看到「媽媽保留的」金額。

**大額入帳提醒**：可以用的錢收到 ≥ $1,000 的入帳時（例：外婆轉入 $2,000），首頁跳出小卡：「收到 $2,000！要不要存一部分到球鞋基金？」→［存 $500］［自己決定金額］［先不要］

### 3.4 夢想達成

**觸發**：存入當下「我存的＋媽媽保留的」≥ 目標。

1. 存入當下：toast「目標達成！媽媽的 $500 會在這週日 20:00 撥進你的帳戶」
2. 週日結算時（Demo 用控制台「跳到週日結算」）顯示慶祝畫面：
   - 藍色圓形打勾圖示
   - 「夢想達成！」＋「球鞋基金 $1,800」
   - 進度條滿格（藍 $1,300＋粉紅 $500）
   - 粉紅小卡：「媽媽的 $500 已撥入你的帳戶」
   - 按鈕「設定下一個夢想」

整個 App **只在兩個時刻**放慶祝畫面：夢想達成、任務禮物到手。

### 3.5 任務

**任務頁**（像集點卡）：

1. 標題「我的任務」＋小字「完成任務，爸媽送你禮物」
2. 任務卡片，每張包含：任務名稱、狀態標籤、進度、禮物（圖示＋文字）。**卡片上不出現任何金額。**

| 任務 | 狀態 | 進度顯示 | 禮物 |
|---|---|---|---|
| 防詐小達人 | 進行中 | 答對 2 / 3 題 | 🎬 週末看電影 |
| 這週不超支 | 進行中 | ●●●●●○○（第 5/7 天） | 🍕 選一次晚餐 |
| 比價小幫手 | 等爸媽確認 | 已回報 | 🗺️ 決定去哪玩 |
| 每一筆都想一下 | 禮物到手（實心標籤） | 爸媽已確認 | 🌙 晚睡半小時 |

3. 虛線按鈕「我做完了，通知爸媽」→ 選擇任務 → 可選填一句回報（例：「我比了全家和 7-11 的鮮奶，7-11 便宜 5 元」）→ 送出後卡片變為「等爸媽確認」

**任務狀態**（只有三種）：`進行中` → `等爸媽確認` → `禮物到手`
- 進度（例：答對 2/3 題、5/7 天）**只供參考**，不會自動變成完成
- 完成與否**只由家長按「已完成」決定**

**禮物到手畫面**（家長按完成後，孩子端立即出現）：
- 暖黃圓形星星圖示
- 「爸媽確認你完成了！」＋任務名稱「比價小幫手」
- 暖黃卡片：「禮物到手｜🗺️ 決定週末去哪玩」
- 小字：「已收進『我的禮物』」
- 按鈕「查看我的禮物」→ 列出所有已獲得的禮物（像徽章收藏）

### 3.6 學堂

**課程列表**：分三類，每堂約 3 分鐘，每堂 1 題小測驗。

```
學堂（一堂約 3 分鐘）
聰明消費
  ▶ 什麼是預算？
  ▶ 需要 vs 想要
  ? 比價小技巧
存錢
  ▶ 複利：讓錢自己長大
防詐
  ▶ 假買家詐騙                    已完成
  ? 借帳戶給別人？               [任務]
  ? 可疑連結與假客服
```

- ▶ 圖示＝影片課（Demo 以縮圖＋播放鍵示意，點下直接顯示文字內容）
- ? 圖示＝圖文＋題目
- 與任務連動的課程顯示暖黃「任務」標籤
- 完成的課程顯示綠字「已完成」

**課程頁**：標題 → 內容（影片縮圖或文字）→ 小測驗 1 題 → 答題回饋。完整內容見第 6 節。

**防詐小測驗（任務用）**：「防詐小達人」任務＝看完「假買家詐騙」影片＋答對 3 題防詐題（6.4 的 3 題）。
- 畫面：標題「防詐小測驗」＋「第 2／3 題」＋進度條 → 題目 → 選項 → 答對時選項變綠並打勾，下方綠卡：「答對了！真正的買家不會要你操作網銀」＋小字「遇到可疑的事，打 165 反詐騙專線」
- 每答完一題，任務卡進度同步更新（2/3 → 3/3），並同步一則動態到家長端；**仍需家長按「已完成」**

### 3.7 帳本

沿用原設計：本月分類、需要 vs 想要比例、每週 30 秒回顧（「這週最值得的一筆花費是？」）、手機條碼載具品項、手動補記。

### 3.8 安全（孩子端）

#### A. 遇到可疑的事（沿用原設計）

- 首頁、學堂內都可以按
- 選擇狀況（選填）：有人要我轉錢／借帳戶、我已經轉出去了、收到奇怪的訊息、其他
- 送出後：通知家長並附上「小安主動向你求助，請先陪伴，不要責備」；顯示 165 反詐騙諮詢專線
- 只暫停轉帳，刷卡與手機付款照常；家長或永豐客服可解除

#### B. 幫我看看（新增）

讓孩子把可疑的訊息或連結貼進來，App 提示常見詐騙特徵。

**畫面**：
1. 標題「幫我看看」＋小字「把奇怪的訊息或連結貼上來，我幫你檢查」
2. 輸入框（可貼上文字或網址）
3. 按鈕「檢查」

**結果**（Demo 用關鍵字比對，寫死在前端）：

| 偵測到的關鍵字 | 結果標題 | 說明 |
|---|---|---|
| 驗證帳戶、操作網銀、補轉 | 這很像「假買家詐騙」 | 真正的買家不會要你操作網銀 |
| 借帳戶、幫忙收款、轉出去 | 這很像「人頭帳戶詐騙」 | 借帳戶給別人，你可能變成詐騙共犯 |
| 保證獲利、穩賺不賠、高報酬 | 這很像「投資詐騙」 | 保證賺錢的投資都是騙人的 |
| 帳戶異常、點連結、重新登入、中獎、包裹 | 這很像「釣魚連結」 | 銀行不會用簡訊連結要你登入；不要點連結、不要輸入密碼或驗證碼 |
| 都沒有 | 沒有發現常見詐騙關鍵字 | 但如果對方要你轉錢、給密碼或驗證碼，一律先停下來 |

結果下方固定兩個按鈕：［告訴爸媽］（等同送出「遇到可疑的事」，狀況帶入「收到奇怪的訊息」）［打 165］

> 範圍說明：銀行看不到孩子的 LINE、IG 等訊息，「幫我看看」只檢查孩子主動貼進來的內容。正式版能否串接 165 或永豐防詐資料庫，需向永豐確認。

#### C. 交易當下提醒（沿用原設計）

- 人頭帳戶情境：陌生人轉錢進來又要孩子轉出 → 款項保留中不能轉出：「有人轉錢給你又要你轉出去，這是常見的人頭帳戶詐騙。」
- 假買家情境：轉帳備註或對話出現「驗證」「補轉」→「真正的買家不會要你操作網銀，這是假買家詐騙。」

## 5. 關鍵邏輯

### 5.1 夢想進度與「存起來」增加幾 %

```js
// 目前進度
progress = round((saved + matchHeld) / target * 100)            // (820 + 300) / 1800 → 62%

// 付款畫面「存起來」預覽
matchAdd = matchEnabled(source) && !match.paused
  ? Math.min(amount * match.ratio,
             match.weekCap - match.heldThisWeek,
             match.goalCap - match.heldTotal)
  : 0                                                           // min(70×1, 50−0, 500−300) = 50
newProgress = round((saved + amount + matchHeld + matchAdd) / target * 100)   // (820+70+300+50)/1800 → 69%
delta = newProgress - progress                                  // +7%
```

- 百分比四捨五入到整數；「+X%」用四捨五入後的新舊值相減，確保畫面上的數字一致
- 進度上限 100%

### 5.2 週日結算與達標

- 每週日 20:00 結算：本週的配對金額確認保留（`heldTotal += heldThisWeek`，`heldThisWeek = 0`）
- 達標判定：`saved + heldTotal >= target`
- 達標後：配對款從家長帳戶撥入孩子的 MMA → 顯示慶祝畫面 → 夢想結束，可設定下一個
- 配對款不再被配對（不會循環加碼）

### 5.3 配對資格

- 只有家長勾選的來源才會產生配對（預設：付款前存起來、週日剩餘存入）
- 以下不配對：紅包／親友贈與（除非家長勾選）、信託給付、從其他夢想轉入

### 5.4 配對暫停（家庭狀況改變時）

家長在「配對」按「暫停配對」→ 彈出：

1. 「已經保留的 $300 要怎麼處理？」

   - 取消，解除保留（錢留在我的帳戶）
2. 給小安一句話（選填，例：「我們之後一起再開始」）
3. ［確認暫停］

暫停後：
- 不再產生新的配對；孩子仍可正常存錢到夢想基金
- **孩子端只顯示「媽媽的配對暫停中」，不顯示任何原因**
- 若選「照樣給」：進度條粉紅段改為灰色，標示「媽媽保留的 $300（暫停中）」，仍計入進度
- 若選「取消」：粉紅段移除，進度與預計達成日自動重算（例：62% → 46%）

## 6. 學堂內容（寫死在前端）

### 6.1 聰明消費

**① 什麼是預算？**（kind: video，沿用原內容）
- 內容：預算就是先決定錢要怎麼用，再開始花。錢一入帳，先想好這週要存多少、能花多少，就不會到週末才發現錢不夠。
- 題目：錢一入帳，最好先做什麼？
- 選項：先存一部分，再決定能花多少 ✓／先把想買的東西買下來
- 答對：沒錯！先存再花，是理財的第一步。
- 答錯：先花再存，常常會發現沒錢可存喔。

**② 需要 vs 想要**（kind: video，沿用原內容）
- 內容：需要是生活必須的，例如車資、文具；想要是有了會開心、但沒有也沒關係的，例如飲料、漫畫。兩種都可以花，重點是知道自己在花哪一種。
- 題目：一杯手搖飲比較接近？
- 選項：需要／想要 ✓
- 答對：答對了！偶爾買沒關係，知道它是「想要」就好。
- 答錯：再想想：不喝手搖飲，生活會過不下去嗎？

**③ 比價小技巧**（kind: quiz，新增）
- 內容：買東西前先比 2 家，不只看總價，也要看「單價」（例如每 100 毫升多少錢）、會不會真的用完、有沒有運費。便宜但用不完，其實不划算。
- 題目：同一款飲料，A 店 500 毫升 $35，B 店 700 毫升 $45，哪一家比較划算？
- 選項：A 店／B 店 ✓
- 答對：答對了！A 店每 100 毫升 $7，B 店約 $6.4。
- 答錯：算算看每 100 毫升多少錢：A 店 $7，B 店約 $6.4。

## 8. Demo 章節建議

沿用原本「左側章節＋手機畫面＋右側示範控制台」的形式。單手機＝只有孩子端；雙手機＝孩子端＋家長端並排，操作一邊、另一邊即時反應。

| 章 | 標題 | 手機 | 示範重點 | 控制台按鈕 |
|---|---|---|---|---|
| 01 | 首頁與零用錢 | 雙 | 媽媽設定零用錢 → 小安首頁更新；切換「不給零用錢」看首頁變化 | 到了撥款時間／外婆轉入紅包 $2,000 |
| 02 | 付款前：買下去 vs 存起來 | 單 | 珍珠奶茶 $70 → 存起來 62% → 69%；公車不提醒 | 模擬店家掃碼（手搖飲／公車） |
| 03 | 夢想基金與家長配對 | 雙 | 媽媽自選比例與上限 → 小安存錢 → 週日結算 → 達標慶祝 | 跳到週日結算 |
| 04 | 家庭狀況改變：配對暫停 | 雙 | 媽媽暫停配對，選「照樣給」或「取消」→ 小安端只顯示「暫停中」 | — |
| 05 | 任務與禮物 | 雙 | 媽媽出題選禮物 → 小安回報 → 媽媽按「小安已完成」→ 禮物到手 | — |
